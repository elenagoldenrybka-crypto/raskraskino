# Раскраскино — сайт бесплатных раскрасок

Готовый простой сайт: главная, 4 темы, 8 своих раскрасок, кнопки «Распечатать» / «Скачать PNG» / «Скачать SVG»,
места под рекламу (РСЯ, AdSense), sitemap.xml, robots.txt, политика конфиденциальности и плашка про cookies.

## Что где лежит

| Файл / папка | Что это |
| --- | --- |
| `site.config.js` | **Все настройки**: название, адрес сайта, номер Метрики, коды рекламы. Начинайте отсюда. |
| `content/raskraski.json` | Список раскрасок: название, тема, текст описания, имя картинки. |
| `content/categories.json` | Список тем (категорий). |
| `images/` | Картинки раскрасок в формате SVG (лучше всего) или PNG. |
| `src/` | Оформление (`style.css`), кнопки (`app.js`), значок сайта. |
| `build.js` | Сборщик: из всего этого делает готовый сайт в папке `dist/`. |

## Как добавить новую раскраску

1. Положите картинку в папку `images/`, например `zayac.svg`. Чёрные контуры на белом фоне, вертикальный лист (пропорции А4).
2. Откройте `content/raskraski.json` и скопируйте любой блок `{ ... }`, поменяв:
   - `slug` — адрес страницы латиницей, например `raskraska-zayac`;
   - `category` — тема (`eda`, `zhivotnye`, `priroda`, `transport` или новая из `categories.json`);
   - `image` — имя файла картинки;
   - `title`, `short`, `age`, `added` (дата), `text` — 2–3 абзаца своего описания.
3. Не забудьте запятую между блоками. Сайт пересоберётся сам после загрузки на GitHub/Netlify.

## Как посмотреть сайт у себя на компьютере

Нужен [Node.js](https://nodejs.org) (версия 18 или новее). В папке проекта выполните:

```
node build.js
npx serve dist
```

и откройте адрес, который появится (обычно http://localhost:3000).

## Как опубликовать бесплатно

### Вариант 1. Netlify (проще всего)
1. Зарегистрируйтесь на https://app.netlify.com (можно через GitHub).
2. Если проект на GitHub: «Add new site» → «Import an existing project» → выберите репозиторий. Настройки сборки подтянутся из `netlify.toml` сами.
3. Без GitHub: на своём компьютере выполните `node build.js` и перетащите папку `dist` на страницу https://app.netlify.com/drop.
4. Свой домен: Site settings → Domain management → Add domain, затем у регистратора домена пропишите DNS-записи, которые покажет Netlify.

### Вариант 2. GitHub Pages
1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта (кроме `dist`).
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Готово: файл `.github/workflows/pages.yml` сам собирает и публикует сайт при каждом изменении.
   Адрес будет `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
4. Свой домен: Settings → Pages → Custom domain. После этого удалите блок `env: BASE_PATH` из `pages.yml`.

> Для рекламы нужен **свой домен** (например, `raskraskino.ru`): РСЯ и AdSense не принимают сайты на `*.github.io` и `*.netlify.app`.

## Как подключить Метрику и рекламу

1. **Яндекс Метрика**: https://metrika.yandex.ru → «Добавить счётчик» → скопируйте номер (только цифры) в `yandexMetrikaId`.
2. **Яндекс Вебмастер** (https://webmaster.yandex.ru) и **Google Search Console**: добавьте сайт и укажите адрес `https://ваш-домен/sitemap.xml`.
3. **РСЯ**: подайте заявку в Яндекс Партнёрских программах (https://partner.yandex.ru). После одобрения создайте рекламные блоки и вставьте их коды в `adCodes` (`top`, `middle`, `bottom`, `sidebar`). Поставьте `adsEnabled: true`.
4. **AdSense**: https://adsense.google.com → впишите `adsensePublisherId` (вид `pub-...`) — сайт сам создаст файл `ads.txt`. Коды блоков — тоже в `adCodes`.
5. Перед подачей заявок впишите свой e-mail в `email` и проверьте текст на странице «Политика конфиденциальности».

## Лицензия картинок

Все 8 раскрасок в папке `images/` нарисованы специально для этого проекта, их можно свободно использовать на своём сайте.
Новые картинки берите только свои, заказанные или со свободной лицензией (CC0) — чужие раскраски копировать нельзя.
